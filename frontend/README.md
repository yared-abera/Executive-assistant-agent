# Frontend — Executive Assistant dashboard

React + Vite + TypeScript + Socket.IO client.

```bash
npm install
npm run dev
npm test
```

Requires backend on `http://127.0.0.1:8000` via:

```bash
cd ../backend
uvicorn core.asgi:application --reload --host 127.0.0.1 --port 8000
```

See root README for the full demo script and API map.
